Cálculo de Salário

Aplicativo Android desenvolvido em Java para calcular o novo salário de acordo com a porcentagem de aumento selecionada pelo usuário.

Ferramentas Utilizadas

Para o desenvolvimento deste projeto, foram utilizados:

Linguagem: Java
Layout: XML
IDE: Android Studio
Gerenciador de Dependências: Gradle
Componentes Android:
EditText
RadioGroup
RadioButton
Button
AlertDialog
Funcionalidades
Inserção do salário atual.
Seleção da porcentagem de aumento:
40%
45%
50%
Cálculo automático do novo salário.
Exibição do resultado em uma caixa de diálogo.
Formatação do valor com 2 casas decimais.
Interface simples e intuitiva.
Como Funciona

Exemplo de cálculo:

Salário informado:

2500

Aumento de 50%:

2500+(2500×0.5)=3750

Resultado:

R$ 3750,00
